# Clear the Fog

Turn an unclear request into an actionable task through a short conversation.

1. Read the request and prior conversation. Preserve details and decisions the user already supplied. If needed, inspect only relevant existing context to identify what is missing; keep this exploration read-only.
2. Identify the most consequential missing detail: the desired outcome, affected subject, scope, constraint, or definition of success. Ask exactly one focused question about that detail. Use a single question in any question tool; offer a few choices only when they help the user answer.
3. Wait for the answer before asking the next question or beginning implementation. Do not bundle independent questions into one sentence or proceed with a guessed answer because time has passed.
4. Incorporate the answer and repeat only while an unresolved detail would materially change the result. Resolve discoverable facts from available context rather than asking the user to look them up.
5. Once the outcome, boundaries, and completion criteria are clear enough to act without guessing the user's intent, briefly state your understanding and begin the authorized work. Further approval is needed only when the action itself requires it.

During clarification, keep files and external resources unchanged. If the user explicitly delegates a choice, use that authority and record the choice briefly. If the user changes the goal, clarify the revised request. A clear request needs no clarification loop.
